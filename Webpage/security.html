Security & Privacy

How this site is secured

A study site for a security certification should practice what it teaches. This page documents the defenses in place, what the last audit found, what data is stored, and what is knowingly left as residual risk.

Defense in depth

Browser-side

  • Strict Content-Security-Policy: scripts only from this origin; no inline script anywhere (including the 11 interactive diagrams)
  • All dynamic text is escaped before it touches the DOM
  • HSTS with preload, nosniff, frame protection, locked-down Permissions-Policy, COOP and CORP
  • No third-party scripts, trackers, or analytics

Accounts & sessions

  • Passwords hashed with scrypt and a per-user random salt; never stored or logged in plain text
  • Session token is HMAC-signed and lives in an HttpOnly, Secure, SameSite=Strict __Host- cookie, so page JavaScript can never read it
  • 30-day sessions, revocable on every device with "Sign out everywhere"
  • Per-account lockout and per-IP rate limits; identical errors for unknown users and wrong passwords

API & storage

  • CSRF defense: custom header, same-origin Origin check, and JSON-only bodies
  • Strict allow-list validation of every synced key, type, and size
  • Private object storage: nothing is reachable by URL
  • Fails closed: if the signing secret is missing, the API refuses to run

Known limits

No multi-factor authentication

Accounts are protected by a password only. The data behind them is low-stakes (study progress), which is why MFA was left out. Use a unique password.

Lockout trade-off

Five wrong passwords lock an account for 15 minutes. That stops guessing, but it also means someone could lock you out briefly. It is a deliberate choice for a site with no email recovery channel.

GitHub Pages mirror

A secondary copy on GitHub Pages cannot send security headers or run the API. It works in local-only mode. The Vercel site is the canonical, hardened deployment.

Reporting an issue

Found something? See security.txt for contact details. This is a personal study project with no bounty, but good-faith reports are welcome and appreciated.
